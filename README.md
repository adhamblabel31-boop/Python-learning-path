## About This Repository

This repository documents **my personal Python learning journey**. It contains structured notes, hands-on examples, exercises, and small projects that reflect my progress while learning Python step by step.

🐍 Python Learning Path

  A structured Python practice repository organized as numbered topic folders. It contains short standalone scripts, small Flask applications, SQLite exercises, NumPy examples,
  file-handling practice, and a checked-in virtual environment directory.

  ────────────────────────────────────────


  📚 Topics Covered

  1.DataType & Operator

  Covers Python basics, strings, numbers, lists, tuples, sets, dictionaries, booleans, and operators.

  2.Input

  Simple input-driven scripts for full-name formatting, email parsing, and age calculation.

  3.If

  Conditional logic using if, elif, else, nested conditions, membership checks, and small decision-based exercises.

  4.Loop

  Examples of while and for loops, iteration over collections, range(), nested loops, and loop control statements.

  5.Function

  Function definitions, arguments, default parameters, packing/unpacking, scope, recursion, lambda functions, built-in functions, and module usage.

  6.File Handling

  Opening, reading, writing, appending, and inspecting files, with two sample text files used by the scripts.

  7.Regular Expressions

  A single script focused on pattern matching with Python's re module.

  8.OOP

  Object-oriented programming examples covering classes, instance attributes, magic methods, inheritance, multiple inheritance, polymorphism, encapsulation, getters/setters, properties,
  and abstract base classes.

  9.Data Base

  SQLite practice scripts for creating tables, inserting data, retrieving data, updating, deleting, and building a small skills-oriented database example.

  10.Flask

  A sequence of Flask examples that progresses from basic routes to HTML templates, template inheritance, Jinja rendering, multiple pages, CSS styling, list-driven rendering, and
  JavaScript-enhanced pages.

  11.Numpy

  NumPy introduction, array creation, data types, slicing, arithmetic operations, shape/reshape operations, and memory/performance comparison.

  12.Virtual Environment

  Scripts related to creating and using virtual environments, plus a checked-in envs/ directory and a requirements.txt file containing ascii-train.

  13.Extras

  Additional Python topics including datetime, iterables and iterators, generators, decorators, zip(), Pillow, comments and docstrings, code style, exceptions, debugging, type hints,
  __name__ == "__main__", timeit, logging, unit testing, random serial generation, Selenium, match/case, Turtle graphics, and a final resources note.

  ▶️ How to Run

  Most files are standalone Python scripts and can be run directly from the repository root:

  python3 "1.DataType & Operator/1_9.basic.py"
  python3 "11.Numpy/142.intro_numpy.py"
  python3 "13.Extras/129.timingWithTimeit.py"

  For Flask examples, run the script from inside its numbered application folder so the local templates/ and static/ directories resolve correctly:

  cd "10.Flask/140"
  python3 140.py

  The Flask examples run with debug=True and use port 9999 in the source files.

  Some scripts require third-party packages to be installed before they can run, including examples that import Flask, NumPy, Pillow, Selenium, PyFiglet, Termcolor, or ascii_train.

  ────────────────────────────────────────

  📈 Learning Progress

  The repository moves from introductory Python syntax and data types into user input, conditional statements, loops, and functions. It then advances into file handling, regular
  expressions, object-oriented programming, database work with SQLite, and web development with Flask.

  Later sections add scientific computing with NumPy and a collection of extra topics such as generators, decorators, logging, testing, debugging, type hints, browser automation, and
  basic graphics. The folder numbering reflects a progression from core language fundamentals toward broader Python tooling and application-building examples.
