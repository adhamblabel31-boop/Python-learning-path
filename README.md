## About This Repository

This repository documents **my personal Python learning journey**. It contains structured notes, hands-on examples, exercises, and small projects that reflect my progress while learning Python step by step.

The goal of this repo is simple:

- Learn Python by **writing code**, not just reading theory
- Keep **clear notes** for fast revision
- Practice consistently through exercises and mini projects

---

## What You’ll Find Here

- **Notes/** — Clean, well-written Markdown notes for each Python topic
- **examples/** — Small runnable Python files to demonstrate concepts
- **exercises/** — Practice problems (with solutions when needed)
- **projects/** — Mini projects that combine multiple Python concepts
